## ข้อสอบชุดที่ 1: ท่อ 3 ท่อนต่ออนุกรมวางเอียง (Three Pipes in Series with Incline)
*(จากเอกสารหน้า 2 และเฉลยที่อาจารย์เขียนในหน้า 3)*

### โจทย์
กำหนดค่า Kinematic Viscosity น้ำ $\nu = 10^{-6}\text{ m}^2/\text{s}$  
ท่อ 3 ท่อนเชื่อมต่อกันตามรูป มุมเอียงของแนวท่อ $\theta = 5^\circ$  
ผลต่างความดันระหว่างจุด A และ B คือ $P_A - P_B = 245.25\text{ kPa}$  
จงประมาณค่าความเร็วของการไหลในท่อแต่ละท่อน ($v_1, v_2, v_3$)

| Pipe no. | Diameter $D$ (m) | Length $L$ (m) | Roughness $\varepsilon$ (mm) |
| :---: | :---: | :---: | :---: |
| 1 | 0.4 | 80 | 0.08 |
| 2 | 0.5 | 120 | 0.15 |
| 3 | 0.3 | 80 | 0.12 |

---

### ขั้นตอนการทำอย่างละเอียด (Step-by-Step)

#### ขั้นที่ 1: กำหนด Datum และคำนวณระดับความสูง $z_B$
*   กำหนดจุด A เป็นระนาบอ้างอิง:
    $$z_A = 0\text{ m}$$
*   ความยาวท่อรวมตลอดแนวเอียง:
    $$L_{\text{total}} = L_1 + L_2 + L_3 = 80 + 120 + 80 = 280\text{ m}$$
*   หาระดับความสูงของจุด B ($z_B$):
    $$z_B = L_{\text{total}} \sin 5^\circ = 280 \sin 5^\circ = 24.40\text{ m}$$

---

#### ขั้นที่ 2: คำนวณหาค่าสัมประสิทธิ์การสูญเสียรอง (Minor Loss Coefficients)
จากชาร์ตการสูญเสียรองที่อาจารย์ให้มา:

1.  **รอยต่อท่อ 1 ไปท่อ 2 (Sudden Expansion):**
    $$\frac{A_1}{A_2} = \frac{\frac{\pi}{4}(0.4)^2}{\frac{\pi}{4}(0.5)^2} = \left(\frac{0.4}{0.5}\right)^2 = 0.64$$
    จากกราฟ Sudden Expansion ที่ $\frac{A_1}{A_2} = 0.64$ จะได้:
    $$K_{12} = 0.15$$
    $$h_{m, 12} = K_{12} \frac{v_1^2}{2g} = 0.15 \frac{v_1^2}{2g}$$

2.  **รอยต่อท่อ 2 ไปท่อ 3 (Sudden Contraction):**
    $$\frac{A_3}{A_2} = \frac{\frac{\pi}{4}(0.3)^2}{\frac{\pi}{4}(0.5)^2} = \left(\frac{0.3}{0.5}\right)^2 = 0.36$$
    จากกราฟ Sudden Contraction ที่ $\frac{A_3}{A_2} = 0.36$ จะได้:
    $$K_{23} = 0.35$$
    $$h_{m, 23} = K_{23} \frac{v_3^2}{2g} = 0.35 \frac{v_3^2}{2g}$$

---

#### ขั้นที่ 3: ใช้สมการความต่อเนื่อง (Continuity Equation)
การไหลเป็นแบบไหลต่อเนื่องผ่านท่ออนุกรม ดังนั้นอัตราการไหลเท่ากันทุกท่อน:
$$Q_1 = Q_2 = Q_3$$
$$v_1 A_1 = v_2 A_2 = v_3 A_3$$

1.  **แปลง $v_2$ ให้อยู่ในรูป $v_1$:**
    $$v_2 = v_1 \frac{A_1}{A_2} = v_1 \left(\frac{0.4}{0.5}\right)^2 = 0.64 v_1$$
2.  **แปลง $v_3$ ให้อยู่ในรูป $v_1$:**
    $$v_3 = v_1 \frac{A_1}{A_3} = v_1 \left(\frac{0.4}{0.3}\right)^2 = \left(\frac{16}{9}\right) v_1 \approx 1.78 v_1$$

---

#### ขั้นที่ 4: ตั้งสมการพลังงานระหว่างจุด A และ B (Energy Equation)
$$\frac{P_A}{\gamma} + \frac{v_A^2}{2g} + z_A = \frac{P_B}{\gamma} + \frac{v_B^2}{2g} + z_B + \sum h_L$$

เนื่องจากจุด A อยู่ในท่อ 1 ($v_A = v_1$) และจุด B อยู่ในท่อ 3 ($v_B = v_3$):
$$\frac{P_A}{\gamma} + \frac{v_1^2}{2g} + 0 = \frac{P_B}{\gamma} + \frac{v_3^2}{2g} + z_B + \left( f_1 \frac{L_1}{D_1}\frac{v_1^2}{2g} + f_2 \frac{L_2}{D_2}\frac{v_2^2}{2g} + f_3 \frac{L_3}{D_3}\frac{v_3^2}{2g} \right) + K_{12}\frac{v_1^2}{2g} + K_{23}\frac{v_3^2}{2g}$$

ย้ายข้างกลุ่มความดันและระดับความสูงมาไว้ฝั่งซ้าย:
$$\frac{P_A - P_B}{\gamma} - z_B = \frac{v_3^2}{2g} - \frac{v_1^2}{2g} + f_1 \frac{L_1}{D_1}\frac{v_1^2}{2g} + f_2 \frac{L_2}{D_2}\frac{v_2^2}{2g} + f_3 \frac{L_3}{D_3}\frac{v_3^2}{2g} + 0.15\frac{v_1^2}{2g} + 0.35\frac{v_3^2}{2g}$$

คำนวณฝั่งซ้ายของสมการ:
*   $\frac{P_A - P_B}{\gamma} = \frac{245.25 \times 10^3\text{ N/m}^2}{9,810\text{ N/m}^3} = 25.00\text{ m}$
*   $\frac{P_A - P_B}{\gamma} - z_B = 25.00 - 24.40 = 0.60\text{ m}$

แทนค่า $v_2 = 0.64 v_1$ และ $v_3 = 1.78 v_1$ ลงในฝั่งขวาแล้วดึงตัวร่วม $\frac{v_1^2}{2g}$ ออกมา:
$$0.60 = \left[ (1.78)^2 - 1 + f_1 \frac{80}{0.4} + f_2 \frac{120}{0.5}(0.64)^2 + f_3 \frac{80}{0.3}(1.78)^2 + 0.15 + 0.35(1.78)^2 \right] \frac{v_1^2}{2g}$$

รวมพจน์คงที่ในวงเล็บ:
*   $(1.78)^2 - 1 = 3.1684 - 1 = 2.1684$
*   $0.15 + 0.35(1.78)^2 = 0.15 + 1.1089 = 1.2589$
*   ผลรวมพจน์คงที่ $= 2.1684 + 1.2589 = 3.4273$
*   พจน์แรงเสียดทานท่อ 1: $f_1 \left(\frac{80}{0.4}\right) = 200 f_1$
*   พจน์แรงเสียดทานท่อ 2: $f_2 \left(\frac{120}{0.5}\right)(0.64)^2 = 240 \times 0.4096 f_2 = 98.30 f_2$
*   พจน์แรงเสียดทานท่อ 3: $f_3 \left(\frac{80}{0.3}\right)(1.78)^2 = 266.67 \times 3.1684 f_3 = 844.91 f_3$

จะได้สมการหลักที่อาจารย์ใช้:
$$0.60 = \left[ 3.427 + 200 f_1 + 98.30 f_2 + 844.91 f_3 \right] \frac{v_1^2}{2g}$$

---

#### ขั้นที่ 5: คำนวณหาค่า Relative Roughness ของท่อแต่ละท่อน
*   ท่อ 1: $\frac{\varepsilon_1}{D_1} = \frac{0.08\text{ mm}}{400\text{ mm}} = 0.0002$
*   ท่อ 2: $\frac{\varepsilon_2}{D_2} = \frac{0.15\text{ mm}}{500\text{ mm}} = 0.0003$
*   ท่อ 3: $\frac{\varepsilon_3}{D_3} = \frac{0.12\text{ mm}}{300\text{ mm}} = 0.0004$

---

#### ขั้นที่ 6: การทำ Trial and Error (สมมุติค่าตามที่อาจารย์สอน)

**รอบที่ 1 (Trial 1):**
สมมุติการไหลอยู่ในโซน Fully Turbulent จากชาร์ตท่อ:
*   $f_1 = 0.014$ (ที่ $k/D = 0.0002$)
*   $f_2 = 0.015$ (ที่ $k/D = 0.0003$)
*   $f_3 = 0.016$ (ที่ $k/D = 0.0004$)

แทนค่าลงในสมการหลัก:
$$\text{Bracket} = 3.427 + 200(0.014) + 98.30(0.015) + 844.91(0.016) = 3.427 + 2.80 + 1.475 + 13.519 = 21.22$$
$$0.60 = 21.22 \frac{v_1^2}{2(9.81)} \implies v_1 = \sqrt{\frac{0.60 \times 19.62}{21.22}} = 0.745\text{ m/s}$$
คำนวณความเร็วท่ออื่น:
*   $v_2 = 0.64(0.745) = 0.477\text{ m/s}$
*   $v_3 = 1.78(0.745) = 1.326\text{ m/s}$

คำนวณ Reynolds Number:
*   $Re_1 = \frac{v_1 D_1}{\nu} = \frac{0.745 \times 0.4}{10^{-6}} = 2.98 \times 10^5$
*   $Re_2 = \frac{v_2 D_2}{\nu} = \frac{0.477 \times 0.5}{10^{-6}} = 2.39 \times 10^5$
*   $Re_3 = \frac{v_3 D_3}{\nu} = \frac{1.326 \times 0.3}{10^{-6}} = 3.98 \times 10^5$

เปิดชาร์ตท่อ (Glasgow Chart) อ่านค่า $f$ ใหม่:
*   ที่ $Re_1 = 3.0 \times 10^5, k/D = 0.0002 \implies f_1 \approx 0.0163$
*   ที่ $Re_2 = 2.4 \times 10^5, k/D = 0.0003 \implies f_2 \approx 0.0175$
*   ที่ $Re_3 = 4.0 \times 10^5, k/D = 0.0004 \implies f_3 \approx 0.0173$

---

**รอบที่ 2 (Trial 2):**
แทนค่า $f_1 = 0.0163, f_2 = 0.0175, f_3 = 0.0173$:
$$\text{Bracket} = 3.427 + 200(0.0163) + 98.30(0.0175) + 844.91(0.0173) = 3.427 + 3.260 + 1.720 + 14.617 = 23.02$$
$$0.60 = 23.02 \frac{v_1^2}{2(9.81)} \implies v_1 = \sqrt{\frac{0.60 \times 19.62}{23.02}} = 0.715\text{ m/s}$$
คำนวณความเร็วท่ออื่น:
*   $v_2 = 0.64(0.715) = 0.458\text{ m/s}$
*   $v_3 = 1.78(0.715) = 1.273\text{ m/s}$

ตรวจสอบ $Re$ ใหม่:
*   $Re_1 = 2.86 \times 10^5 \implies f_1 \approx 0.0163$ (ตรงเดิม!)
*   $Re_2 = 2.29 \times 10^5 \implies f_2 \approx 0.0175$ (ตรงเดิม!)
*   $Re_3 = 3.82 \times 10^5 \implies f_3 \approx 0.0173$ (ตรงเดิม!)

**คำตอบลู่เข้าสมบูรณ์ (Converged)!**

### สรุปคำตอบข้อที่ 1

*   อัตราการไหล $Q = v_1 A_1 = 0.713 \times \frac{\pi}{4}(0.4)^2 = 0.0896\text{ m}^3/\text{s} = 89.6\text{ L/s}$

## ข้อสอบชุดที่ 2: ท่อขนาดสม่ำเสมอปล่อยออกสู่บรรยากาศ (หาขนาดเส้นผ่านศูนย์กลางท่อ $D$)
*(จากเอกสารหน้า 2 ข้อ 2)*

### โจทย์
น้ำไหลในท่อขนาดคงที่ โดยทางออกอยู่ที่จุด 2 ปล่อยออกสู่บรรยากาศ  
จุด 2 อยู่สูงกว่าจุด 1 อยู่ $10\text{ m}$ ($z_2 - z_1 = 10\text{ m}$)  
ความยาวท่อระหว่างจุด 1 ถึง 2 คือ $L = 1,500\text{ m}$  
อัตราการไหล $Q = 0.14\text{ m}^3/\text{s}$  
ค่าความขรุขระ $\varepsilon = 0.9\text{ mm}$  
ความดันที่จุด 1 คือ $P_1 = 105.13\text{ kPa}$  
จงหาขนาดเส้นผ่านศูนย์กลางท่อ ($D$)

---

### ขั้นตอนการทำอย่างละเอียด (Step-by-Step)

#### ขั้นที่ 1: ตั้งสมการพลังงานระหว่างจุด 1 และจุด 2
$$\frac{P_1}{\gamma} + \frac{v_1^2}{2g} + z_1 = \frac{P_2}{\gamma} + \frac{v_2^2}{2g} + z_2 + h_f$$

เงื่อนไขทางกายภาพ:
*   ท่อมีขนาดสม่ำเสมอคงที่ $\implies D_1 = D_2 \implies v_1 = v_2 \implies \frac{v_1^2}{2g} = \frac{v_2^2}{2g}$ (ตัดกันได้)
*   จุด 2 เป็นปลายท่อพุ่งออกสู่อากาศ $\implies P_2 = 0\text{ kPa (เกจ)}$
*   ผลต่างระดับความสูง: $z_2 - z_1 = 10\text{ m}$

แทนค่า:
$$\frac{105.13 \times 10^3}{9,810} + 0 = 0 + 10 + h_f$$
$$10.717 = 10 + h_f \implies h_f = 0.717\text{ m}$$

---

#### ขั้นที่ 2: จัดรูปสูตรหาเส้นผ่านศูนย์กลาง $D$
จาก Darcy-Weisbach:
$$h_f = \frac{8 f L Q^2}{\pi^2 g D^5} \implies D = \left( \frac{8 f L Q^2}{\pi^2 g h_f} \right)^{1/5}$$

แทนค่าคงที่ลงในสูตร:
$$\frac{8 L Q^2}{\pi^2 g h_f} = \frac{8(1500)(0.14)^2}{\pi^2(9.81)(0.7166)} = \frac{235.2}{69.378} = 3.390\times 10^0$$
$$D = (3.390 \times f)^{0.2} = 3.390^{0.2} \times f^{0.2} = 1.2766 \times f^{0.2}$$

---

#### ขั้นที่ 3: การทำ Trial and Error

*   **Trial 1:** สมมุติค่า $f_1 = 0.020$
    $$D_1 = \left( \frac{8(0.020)(1500)(0.14)^2}{\pi^2(9.81)(0.7166)} \right)^{1/5} = 0.584\text{ m} = 584\text{ mm}$$
    คำนวณความเร็ว $v$:
    $$v = \frac{4Q}{\pi D^2} = \frac{4(0.14)}{\pi (0.584)^2} = 0.523\text{ m/s}$$
    คำนวณ $Re$ และ Relative Roughness:
    $$Re = \frac{v D}{\nu} = \frac{0.523 \times 0.584}{10^{-6}} = 3.05 \times 10^5$$
    $$\frac{\varepsilon}{D} = \frac{0.9\text{ mm}}{584\text{ mm}} = 0.00154$$
    เปิดชาร์ตท่อ (ที่อาจารย์วงไว้ในชาร์ตหน้า 1 เส้นสีชมพู $k/d = 0.0015$ อ่านได้ค่า $f = 0.023$ พอดีเป๊ะ!):
    $$f_2 = 0.0225 - 0.023$$

*   **Trial 2:** แทนค่า $f_2 = 0.0226$
    $$D_2 = \left( \frac{8(0.0226)(1500)(0.14)^2}{\pi^2(9.81)(0.7166)} \right)^{1/5} = 0.598\text{ m} \approx 600\text{ mm}$$
    ตรวจสอบ $Re$:
    $$v = \frac{4(0.14)}{\pi (0.598)^2} = 0.498\text{ m/s}$$
    $$Re = \frac{0.498 \times 0.598}{10^{-6}} = 2.98 \times 10^5$$
    $$\frac{\varepsilon}{D} = \frac{0.9}{598} = 0.00150 \implies f = 0.0225 \quad (\text{คงที่!})$$

### สรุปคำตอบข้อที่ 2
*   **เส้นผ่านศูนย์กลางท่อ $D = 0.60\text{ m} = 600\text{ mm}$ (หรือ $598\text{ mm}$)**

## ข้อสอบชุดที่ 3: ถังเก็บน้ำขนาดใหญ่ 2 ถังเชื่อมด้วยท่อเอียง (Two Huge Tanks)
*(จากเอกสารหน้า 1 แผ่นที่ 2)*

### โจทย์
จงหาขนาดเส้นผ่านศูนย์กลางท่อ ($D$)  
กำหนดให้ถังทั้งสองเป็นถังขนาดใหญ่มาก (Huge Tanks)  
อัตราการไหลในท่อ $Q = 12\text{ m}^3/\text{s}$  
ค่าความขรุขระท่อ $\varepsilon = 0.48\text{ mm}$  
ความหนาแน่นน้ำ $\rho = 1,000\text{ kg/m}^3$ และ Viscosity $\mu = 10^{-3}\text{ N}\cdot\text{s/m}^2$ ($\nu = 10^{-6}\text{ m}^2/\text{s}$)  
ความยาวท่อ $L = 120\text{ m}$ ทำมุมเอียงขึ้น $12^\circ$  
ระดับผิวน้ำถังซ้ายอยู่สูงกว่าปากทางเข้าท่อ $45\text{ m}$  
ระดับผิวน้ำถังขวาอยู่สูงกว่าปากทางออกท่อ $16.5\text{ m}$  
สามารถละเว้นการสูญเสียรองได้ (Minor loss can be ignored)

---

### ขั้นตอนการทำอย่างละเอียด (Step-by-Step)

#### ขั้นที่ 1: กำหนด Datum และคำนวณผลต่างระดับผิวน้ำ $h_f$
*   กำหนดทางเข้าท่อฝั่งซ้ายเป็น Datum ($z_{\text{in}} = 0$)
*   ระดับผิวน้ำถัง 1 (ถังซ้าย):
    $$z_1 = z_{\text{in}} + 45.0 = 45.0\text{ m}$$
*   ทางออกท่อฝั่งขวาอยู่สูงขึ้นไปตามแนวเอียง $12^\circ$:
    $$z_{\text{out}} = L \sin 12^\circ = 120 \sin 12^\circ = 120(0.2079) = 24.95\text{ m}$$
*   ระดับผิวน้ำถัง 2 (ถังขวา):
    $$z_2 = z_{\text{out}} + 16.5 = 24.95 + 16.5 = 41.45\text{ m}$$
*   ตั้งสมการพลังงานระหว่างผิวน้ำถัง 1 และถัง 2:
    $$\frac{P_1}{\gamma} + \frac{v_1^2}{2g} + z_1 = \frac{P_2}{\gamma} + \frac{v_2^2}{2g} + z_2 + h_f$$
    เนื่องจากผิวน้ำถังขนาดใหญ่เปิดสู่บรรยากาศ $P_1 = P_2 = 0$ และ $v_1 \approx v_2 \approx 0$:
    $$z_1 = z_2 + h_f \implies h_f = z_1 - z_2 = 45.0 - 41.45 = 3.55\text{ m}$$

---

#### ขั้นที่ 2: การทำ Trial and Error หาขนาดท่อ $D$
จากสูตร $D = \left( \frac{8 f L Q^2}{\pi^2 g h_f} \right)^{1/5}$:

*   **Trial 1:** เริ่มต้นสมมุติ $f = 0.020$
    $$D_1 = \left( \frac{8(0.020)(120)(12)^2}{\pi^2(9.81)(3.55)} \right)^{1/5} = 1.517\text{ m}$$
    $$v = \frac{4(12)}{\pi (1.517)^2} = 6.64\text{ m/s}$$
    $$Re = \frac{6.64 \times 1.517}{10^{-6}} = 1.01 \times 10^7$$
    $$\frac{\varepsilon}{D} = \frac{0.48\text{ mm}}{1517\text{ mm}} = 0.00032$$
    เปิดชาร์ตท่อที่ $Re = 1.0 \times 10^7$ และ $k/D = 0.00032 \implies f = 0.0153$

*   **Trial 2:** แทนค่า $f = 0.0153$
    $$D_2 = \left( \frac{8(0.0153)(120)(12)^2}{\pi^2(9.81)(3.55)} \right)^{1/5} = 1.439\text{ m}$$
    $$v = \frac{4(12)}{\pi (1.439)^2} = 7.38\text{ m/s}$$
    $$Re = \frac{7.38 \times 1.439}{10^{-6}} = 1.06 \times 10^7$$
    $$\frac{\varepsilon}{D} = \frac{0.48}{1439} = 0.00033 \implies f = 0.0153 \quad (\text{ลู่เข้าตรงเป๊ะ!})$$

### สรุปคำตอบข้อที่ 3
*   **ขนาดเส้นผ่านศูนย์กลางท่อ $D = 1.44\text{ m} \approx 1,440\text{ mm}$**

## ข้อสอบชุดที่ 4: โครงข่ายท่ออนุกรม-ขนาน 4 ท่อน (Parallel & Series Pipe Network)
*(จากเอกสารหน้า 4 - ข้อสอบ 15 คะแนน)*

### โจทย์
ท่อ 4 ท่อนเชื่อมต่อกันตามรูป โดยท่อ 1 ต่ออนุกรม แล้วแยกขนานเป็นท่อ 2 และท่อ 3 จากนั้นรวมกลับมาเข้าท่อ 4  
จงประมาณค่าการสูญเสียหลัก (Major losses) จากจุด AA ถึง BB ($h_{AA \to BB}$)  
*   จุด A อยู่ต่ำกว่าจุด B อยู่ $10\text{ m}$ ($z_B - z_A = 10\text{ m}$)  
*   ความยาวช่วง A ถึง B บนท่อ 4 คือ $L_{AB} = 300\text{ m}$  
*   กำหนด Major head loss ในท่อ 3 คือ $h_3 = 0.42\text{ m}$  
*   ความดันที่จุด A และ B คือ $P_A = 910\text{ kPa}$ และ $P_B = 811.41\text{ kPa}$  
*   ละเว้นการสูญเสียรอง (Minor loss can be ignored)

| Pipe | Diameter $D$ (m) | Pipe length $L$ (m) | Roughness $\varepsilon$ (mm) |
| :---: | :---: | :---: | :---: |
| 1 | 0.9 | 900 | 0.90 |
| 2 | 0.8 | 800 | 0.32 |
| 3 | 0.6 | 800 | 0.48 |
| 4 | - | 1,000 | 0.96 |

---

### ขั้นตอนการทำอย่างละเอียด (Step-by-Step)

#### ขั้นที่ 1: วิเคราะห์ช่วงท่อ 4 ระหว่างจุด A และ B เพื่อหา Head Loss ของท่อ 4
ตั้งสมการพลังงานระหว่างจุด A และ B บนท่อ 4:
$$\frac{P_A}{\gamma} + \frac{v_A^2}{2g} + z_A = \frac{P_B}{\gamma} + \frac{v_B^2}{2g} + z_B + h_{AB}$$

เนื่องจากจุด A และ B อยู่บนท่อ 4 ซึ่งมีขนาดเส้นผ่านศูนย์กลางคงที่ตลอดเส้น $\implies v_A = v_B$:
$$\frac{P_A - P_B}{\gamma} = (z_B - z_A) + h_{AB}$$

แทนค่าตัวเลข:
$$\frac{(910 - 811.41) \times 10^3\text{ N/m}^2}{9,810\text{ N/m}^3} = 10\text{ m} + h_{AB}$$
$$\frac{98.59 \times 10^3}{9,810} = 10.05\text{ m}$$
$$10.05 = 10 + h_{AB} \implies h_{AB} = 0.05\text{ m}$$

เนื่องจากการสูญเสียหลักแปรผันตรงกับความยาวท่อ ($h_f \propto L$):
$$h_4 = h_{AB} \times \left( \frac{L_4}{L_{AB}} \right) = 0.05 \times \left( \frac{1000}{300} \right) = 0.1667\text{ m} \approx 0.17\text{ m}$$

---

#### ขั้นที่ 2: วิเคราะห์ท่อขนาน (Pipes in Parallel: ท่อ 2 และท่อ 3)
ตามกฎฟิสิกส์ของการไหลในท่อขนาน:
$$h_2 = h_3 = 0.42\text{ m}$$

1.  **หาอัตราการไหลในท่อ 3 ($Q_3$):**
    $$h_3 = f_3 \frac{L_3}{D_3} \frac{v_3^2}{2g} = 0.42\text{ m}$$
    $$\frac{\varepsilon_3}{D_3} = \frac{0.48\text{ mm}}{600\text{ mm}} = 0.0008$$
    เปิดชาร์ตท่อเดาค่า $f_3 \approx 0.019$ (สังเกตเส้นสีน้ำเงินที่อาจารย์เขียนกำกับไว้ที่ $0.019$ บนชาร์ตหน้า 1!):
    $$0.42 = (0.019) \left(\frac{800}{0.6}\right) \frac{v_3^2}{2(9.81)} = 25.333 \times \frac{v_3^2}{19.62} \implies v_3 = \sqrt{\frac{0.42 \times 19.62}{25.333}} = 0.570\text{ m/s}$$
    ตรวจสอบ $Re_3 = \frac{0.570 \times 0.6}{10^{-6}} = 3.42 \times 10^5 \implies f_3 \approx 0.0195$
    ปรับค่า $v_3$:
    $$v_3 = 0.561\text{ m/s}$$
    $$Q_3 = v_3 \frac{\pi}{4}(0.6)^2 = 0.561 \times 0.2827 = 0.1587\text{ m}^3/\text{s}$$

2.  **หาอัตราการไหลในท่อ 2 ($Q_2$):**
    $$h_2 = f_2 \frac{L_2}{D_2} \frac{v_2^2}{2g} = 0.42\text{ m}$$
    $$\frac{\varepsilon_2}{D_2} = \frac{0.32\text{ mm}}{800\text{ mm}} = 0.0004$$
    สมมุติ $f_2 \approx 0.017$:
    $$0.42 = (0.017) \left(\frac{800}{0.8}\right) \frac{v_2^2}{2(9.81)} = 17.0 \times \frac{v_2^2}{19.62} \implies v_2 = \sqrt{\frac{0.42 \times 19.62}{17.0}} = 0.696\text{ m/s}$$
    ตรวจสอบ $Re_2 = \frac{0.696 \times 0.8}{10^{-6}} = 5.57 \times 10^5 \implies f_2 \approx 0.0169$ (คงที่!)
    $$v_2 \approx 0.698\text{ m/s}$$
    $$Q_2 = v_2 \frac{\pi}{4}(0.8)^2 = 0.698 \times 0.5027 = 0.3510\text{ m}^3/\text{s}$$

3.  **หาอัตราการไหลรวมของระบบ ($Q_{\text{total}}$):**
    $$Q_1 = Q_{\text{total}} = Q_2 + Q_3 = 0.3510 + 0.1587 = 0.5097\text{ m}^3/\text{s} \approx 0.51\text{ m}^3/\text{s}$$

---

#### ขั้นที่ 3: คำนวณ Head Loss ในท่อ 1 ($h_1$)
เนื่องจากท่อ 1 รับอัตราการไหลทั้งหมด $Q_1 = 0.5097\text{ m}^3/\text{s}$:
$$v_1 = \frac{4 Q_1}{\pi D_1^2} = \frac{4(0.5097)}{\pi (0.9)^2} = 0.801\text{ m/s}$$
$$\frac{\varepsilon_1}{D_1} = \frac{0.90\text{ mm}}{900\text{ mm}} = 0.0010$$
$$Re_1 = \frac{v_1 D_1}{\nu} = \frac{0.801 \times 0.9}{10^{-6}} = 7.21 \times 10^5$$
เปิดชาร์ตท่อที่ $Re_1 = 7.2 \times 10^5$ และ $k/D = 0.0010$ ได้:
$$f_1 \approx 0.0201$$

คำนวณ $h_1$:
$$h_1 = f_1 \frac{L_1}{D_1} \frac{v_1^2}{2g} = (0.0201) \left(\frac{900}{0.9}\right) \frac{(0.801)^2}{2(9.81)} = (20.1) \times \frac{0.6416}{19.62} = 0.657\text{ m}$$

---

#### ขั้นที่ 4: รวมค่าการสูญเสียหลักจาก AA ถึง BB ($h_{AA \to BB}$)
กฎของท่ออนุกรมผสมขนาน:
$$h_{AA \to BB} = h_1 + h_2 + h_4 \quad (\text{หรือ } h_1 + h_3 + h_4)$$

แทนค่า:
$$h_{AA \to BB} = 0.657 + 0.420 + 0.167 = 1.244\text{ m} \approx 1.24\text{ m}$$

### สรุปคำตอบข้อที่ 4

*   $h_4 = 0.17\text{ m}$
*   $Q_{\text{total}} = 0.51\text{ m}^3/\text{s}$
*   $h_1 = 0.66\text{ m}$
*   $\mathbf{h_{AA \to BB} = 1.24\text{ m}}$
