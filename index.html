🌟 ปูพื้นฐานการไหลในท่อจากศูนย์ (สอนคนไม่รู้อะไรเลย)

สรุปตัวแปรฟิสิกส์ให้เห็นภาพชัดเจน พร้อมคำศัพท์ภาษาอังกฤษวงเล็บไทยกำกับ

1. ตัวแปรพื้นฐานของการไหล (Basic Flow Variables)

  • Discharge / Flow Rate (อัตราการไหลเชิงปริมาตร, $Q$): ปริมาณเนื้อน้ำที่ไหลผ่านหน้าตัดท่อต่อหนึ่งวินาที มีหน่วยเป็น $[\text{m}^3\text{/s}]$ หรือลิตรต่อวินาที $[\text{L/s}]$ โดยที่ $1\text{ m}^3\text{/s} = 1,000\text{ L/s}$
  • Cross-sectional Area (พื้นที่หน้าตัดท่อ, $A$): ท่อกลมมีพื้นที่ $A = \frac{\pi}{4} D^2$ โดย $D$ คือ Diameter (เส้นผ่านศูนย์กลางท่อ) $[\text{m}]$
  • Mean Velocity (ความเร็วเฉลี่ย, $v$): คำนวณจาก: $$v = \frac{Q}{A} = \frac{4Q}{\pi D^2} \quad [\text{m/s}]$$

2. ประเภทการไหล: Laminar vs Turbulent

ตัดสินด้วย Reynolds Number (เลขเรย์โนลด์ส, $Re$):

$$Re = \frac{\rho v D}{\mu} = \frac{v D}{\nu}$$
  • Laminar Flow (การไหลแบบราบเรียบ): $Re \le 2,000$ น้ำไหลขนานกันเป็นระเบียบ ค่าความฝืดคือ $f = \frac{64}{Re}$
  • Turbulent Flow (การไหลแบบปั่นป่วน): $Re \ge 4,000$ น้ำหมุนวนปั่นป่วน เกิดแรงต้านทานสูง ต้องเปิดหาค่าความฝืด $f$ จากชาร์ตท่อ (Moody Diagram)

3. การสูญเสียพลังงานในท่อ (Head Losses)

  • Major Loss (การสูญเสียหลักจากแรงเสียดทาน, $h_f$): เสียดสีกับผนังท่อตลอดความยาว $h_f = f \frac{L}{D} \frac{v^2}{2g}$
  • Minor Loss (การสูญเสียรอง, $h_m$): ชนข้องอ ท่อขยาย ท่อหด $h_m = K \frac{v^2}{2g}$

4. สมการพลังงานรวม (The Energy Equation)

$$\frac{P_1}{\gamma} + \frac{v_1^2}{2g} + z_1 = \frac{P_2}{\gamma} + \frac{v_2^2}{2g} + z_2 + \sum h_L$$
  • • $\frac{P}{\gamma}$: Pressure Head (เฮดความดัน) โดย $\gamma = 9,810\text{ N/m}^3$
  • • $\frac{v^2}{2g}$: Velocity Head (เฮดความเร็ว)
  • • $z$: Elevation Head (เฮดระดับความสูง) เทียบกับ Datum (ระดับอ้างอิง)

🎯 ลำดับการทำ 4 สเต็ปตามที่อาจารย์ตรวจให้คะแนนเต็ม

Step 1

กำหนด Datum & สมการพลังงาน

เขียนสมการพลังงานเต็มรูปแบบ และระบุระดับอ้างอิง $z=0$

Step 2

ยุบตัวแปรด้วย Continuity

แปลงความเร็วทุกท่อนให้อยู่ในรูปตัวแปร $v$ ตัวเดียว เช่น $v_2 = c_2 v_1$

Step 3

ดึงตัวร่วมก้อนวงเล็บใหญ่

รวมพจน์คงที่และค่า $f$ ไว้ในวงเล็บเดี่ยว คูณด้วย $\frac{v^2}{2g}$

Step 4

วนลูป Trial & Error

สมมุติค่า $f$ รอบแรก $\to$ หาความเร็ว $v \to$ เช็ค $Re \to$ อ่าน $f$ ใหม่จนลู่เข้า

📊 วิธีการอ่านชาร์ตความเสียดทานท่อ (Moody / Glasgow Chart)

Glasgow Diagram Simulator คลิกปุ่มด้านบนเพื่อดูแนวเส้นลากอ่านค่า
ข้อที่ 1 (ตัวอย่าง 1 หน้า 1-2)

ตรวจสอบประเภทการไหล และหาความเร็วสูงสุดของ Laminar

$Re = 10,000 \text{ (Turbulent)}, \; v_{\text{max}} = 0.02\text{ m/s}$

1. เช็คประเภทการไหล ($D=0.1\text{ m}, v=0.1\text{ m/s}, \mu=10^{-3}$):

$$Re = \frac{\rho v D}{\mu} = \frac{(1000)(0.1)(0.1)}{10^{-3}} = \mathbf{10,000}$$

เนื่องจาก $Re = 10,000 > 2,000 \implies$ **Turbulent Flow (การไหลแบบปั่นป่วน)**

2. หาความเร็วสูงสุดที่จะยังเป็น Laminar ($Re = 2,000$):

$$2,000 = \frac{(1000) v (0.1)}{10^{-3}} \implies v = \frac{2,000 \times 10^{-3}}{100} = \mathbf{0.02\text{ m/s}}$$

ความเร็วสูงสุดของ Laminar คือ $\mathbf{0.02\text{ m/s}}$

ข้อที่ 2 (ตัวอย่าง 2 หน้า 1-2)

หา Pressure Drop (ความดันลดลง $\Delta P$) ในท่อ

$\Delta P_{\text{laminar}} = 0.05\text{ Pa}, \; \Delta P_{\text{turbulent}} = 15\text{ Pa}$

(ก) เช็คประเภทการไหล ($v=0.02\text{ m/s}, D=0.08\text{ m}$):

$$Re = \frac{(1000)(0.02)(0.08)}{10^{-3}} = \mathbf{1,600}$$

$1,600 < 2,000 \implies$ **Laminar Flow (ราบเรียบ)**

(ข) หา $\Delta P$ ที่ระยะทาง $L = 0.5\text{ m}$ (Laminar):

$$f = \frac{64}{1600} = 0.04$$ $$\Delta P = (0.04)\left(\frac{0.5}{0.08}\right)\frac{(1000)(0.02)^2}{2} = \mathbf{0.05\text{ Pa}}$$

(ค) ท่อพลาสติก $\varepsilon=0.12\text{ mm}, v=1\text{ m/s}, L=0.1\text{ m}$:

$$Re = 8 \times 10^4, \; \frac{\varepsilon}{D} = \frac{0.12}{80} = 0.0015$$ $$\text{Moody } f = 0.024 \implies \Delta P = \mathbf{15\text{ Pa}}$$
ข้อที่ 3 (ตัวอย่าง 3 หน้า 1, 3, 4)

ท่อ 3 ขนาดต่างระดับ หา Energy Loss ($h_L$)

$h_{L, 1-2} = 9.84\text{ m}, \; h_{L, 2-3} = 5.47\text{ m}$

1. จุด 1 ถึง จุด 2 ($Q = 0.1\text{ m}^3\text{/s}$):

$$v_1 = 12.73\text{ m/s} \implies \frac{v_1^2}{2g} = 8.260\text{ m}$$ $$v_2 = 3.18\text{ m/s} \implies \frac{v_2^2}{2g} = 0.515\text{ m}$$ $$H_1 = \frac{100 \times 10^3}{9,810} + 8.260 + 0 = 18.454\text{ m}$$ $$H_2 = \frac{50 \times 10^3}{9,810} + 0.515 + 3 = 8.612\text{ m}$$ $$h_{L, 1-2} = 18.454 - 8.612 = \mathbf{9.84\text{ m}}$$

2. จุด 2 ถึง จุด 3:

$$v_3 = 1.41\text{ m/s} \implies \frac{v_3^2}{2g} = 0.101\text{ m}$$ $$H_3 = \frac{20 \times 10^3}{9,810} + 0.101 + 1 = 3.140\text{ m}$$ $$h_{L, 2-3} = H_2 - H_3 = 8.612 - 3.140 = \mathbf{5.47\text{ m}}$$
ข้อที่ 4 (หน้า 4)

ท่อยาว $600\text{ m}$ ข้องอ 2 ตัว หา Major Loss และ Minor Loss

$h_f = 36.74 - 37.19\text{ m}, \; h_m = 0.52\text{ m}$

1. คำนวณความเร็วและค่าเรย์โนลด์ส:

$D = 0.2\text{ m}, Q = 0.1\text{ m}^3\text{/s}, L = 600\text{ m}, \varepsilon = 0.4\text{ mm}$

$$v = \frac{4(0.1)}{\pi (0.2)^2} = \mathbf{3.183\text{ m/s}} \implies \frac{v^2}{2g} = \mathbf{0.5165\text{ m}}$$ $$Re = \frac{(1000)(3.183)(0.2)}{10^{-3}} = \mathbf{6.37 \times 10^5}, \quad \frac{\varepsilon}{D} = \frac{0.4}{200} = \mathbf{0.0020}$$ $$\text{เปิดชาร์ตได้ } f = \mathbf{0.0238 \approx 0.024}$$

2. คำนวณการสูญเสียหลักและรอง:

• Major Loss (การสูญเสียหลัก, $h_f$):
$$h_f = (0.0238)\left(\frac{600}{0.2}\right)(0.5165) = \mathbf{36.88\text{ m}} \quad (\text{หรือ } 37.19\text{ m เมื่อใช้ } f=0.024)$$
• Minor Loss (การสูญเสียรอง, $h_m$): ข้องอ 2 ตัว $K_L = 0.5 \times 2 = 1.0$
$$h_m = (1.0)(0.5165) = \mathbf{0.52\text{ m}}$$
ข้อที่ 5 (หน้า 4)

ท่อ $D = 0.6\text{ m}$ เดินขึ้นเนิน $20\text{ m}$ หาความดันน้อยที่สุดที่จุด 1

$P_1 = 219.58\text{ kPa} \approx 220\text{ kPa}$

1. ข้อมูลและการสูญเสียพลังงาน:

$D = 0.6\text{ m}, v = 2\text{ m/s}, L = 120\text{ m}, \varepsilon = 3\text{ mm}, z_2 - z_1 = 20\text{ m}$

$$\frac{v^2}{2g} = \frac{2^2}{2(9.81)} = 0.2039\text{ m}, \quad Re = 1.20 \times 10^6, \quad \frac{\varepsilon}{D} = \frac{3}{600} = 0.0050$$ $$f \approx \mathbf{0.0304 \approx 0.030}$$ $$h_f = (0.0304)\left(\frac{120}{0.6}\right)(0.2039) = 1.24\text{ m}$$ $$h_m = (0.3 + 0.3)(0.2039) = 0.12\text{ m} \implies \sum h_L = \mathbf{1.36\text{ m}}$$

2. หาความดัน $P_1$ (สมการพลังงาน):

เนื่องจาก $v_1 = v_2 = 2\text{ m/s}$ Velocity head จึงตัดกันหมด:

$$\frac{P_1}{\gamma} = \frac{P_2}{\gamma} + (z_2 - z_1) + \sum h_L$$ $$\frac{P_1}{\gamma} = \frac{10 \times 10^3}{9,810} + 20 + 1.36 = 1.019 + 20 + 1.36 = \mathbf{22.38\text{ m}}$$ $$P_1 = 22.38 \times 9,810 = 219,548\text{ Pa} = \mathbf{219.58\text{ kPa} \quad (\approx 220\text{ kPa})}$$
ข้อที่ 7 (หน้า 5-6) ⭐ อาจารย์เน้น "ข้อสอบแน่!"

ถังเก็บน้ำลึก 15 m ท่อเดินขึ้นเนิน 10 m พุ่งออกสู่อากาศ

$v = 2.51\text{ m/s} \quad (f = 0.0195)$

1. ตั้งสมการพลังงาน:

จุด 1 (ผิวน้ำ): $P_1=0, v_1=0, z_1=15\text{ m}$
จุด 2 (ออกอากาศ): $P_2=0, v_2=v, z_2=10\text{ m}$
Minor: $K_{\text{ent}}=1.0, K_{\text{elbow}}=0.3 \times 2 = 0.6 \implies \sum K = 1.6$

$$15 - 10 = 5 = \left[ 1 + 1.6 + f \frac{100}{0.15} \right] \frac{v^2}{2g}$$ $$\mathbf{5 = \left[ 2.6 + f \left(\frac{100}{0.15}\right) \right] \frac{v^2}{2g}} \quad (\star)$$

2. ขั้นตอน Trial & Error:

• รอบที่ 1: สมมุติ $f = 0.020 \implies \text{Bracket} = 15.93 \implies v = 2.48\text{ m/s} \implies Re = 3.7 \times 10^5 \implies \text{Moody } f = 0.0195$
• รอบที่ 2: ใช้ $f = 0.0195 \implies \text{Bracket} = 15.60 \implies v = \mathbf{2.51\text{ m/s}} \implies \text{Moody } f = 0.0195 \text{ (ลู่เข้า!)}$
ข้อที่ 8 (หน้า 5, 7)

หาขนาดเส้นผ่านศูนย์กลางท่อ $D$ ด้วยการจัดรูป $D^5$

$D = 0.36\text{ m} = 360\text{ mm}$

1. การจัดรูปตามที่อาจารย์เขียน:

$$v = \frac{4(0.5)}{\pi D^2} = \frac{2}{\pi D^2} \implies v^2 = \frac{4}{\pi^2 D^4}$$ $$10 = f \frac{200}{D} \frac{1}{2g} \left[\frac{4}{\pi^2 D^4}\right] \implies \mathbf{D^5 = \frac{f \times 200 \times 4}{10 \times 2(9.81) \times \pi^2} = \frac{800 f}{1936.43}}$$

2. การวนลูปสมมุติค่า:

• รอบ 1: สมมุติ $f = 0.030 \implies D = 0.42\text{ m} \implies \text{Moody } f = 0.015$

• รอบ 2: ใช้ $f = 0.015 \implies D = 0.36\text{ m} \implies \text{Moody } f = 0.0155$

• รอบ 3: ใช้ $f = 0.0155 \implies \mathbf{D = 0.36\text{ m}}$ (ตรงเดิม ลู่เข้าแล้ว!)

ข้อที่ 6 (หน้า 3, 4)

หาความเร็วในท่อยาว $L = 700\text{ m}, h_L = 3\text{ m}, D = 15\text{ cm}$

$v = 0.77\text{ m/s} \quad (f = 0.021)$

• รอบที่ 1: สมมุติ $f = 0.020 \implies v = 0.79\text{ m/s} \implies Re = 1.2 \times 10^5 \implies \text{Moody } f = 0.021$

• รอบที่ 2: ใช้ $f = 0.021 \implies \mathbf{v = 0.77\text{ m/s}} \implies Re = 1.16 \times 10^5 \implies f = 0.021 \quad (\mathbf{OK!})$

โจทย์ข้อ 9 (หน้า 5, 8)
