1. General Energy Equation

สมการอนุรักษ์พลังงาน (Head Balance)

$$\frac{P_1}{\gamma} + \frac{v_1^2}{2g} + z_1 = \frac{P_2}{\gamma} + \frac{v_2^2}{2g} + z_2 + \sum h_L$$
  • $\gamma = 9,810\text{ N/m}^3$ สำหรับน้ำ
  • $z$: วัดเทียบกับระนาบ Datum เดียวกัน
  • $\sum h_L = \sum h_f + \sum h_m$

2. Darcy-Weisbach Equation

การสูญเสียหลักจากแรงเสียดทาน (Major Loss)

$$h_f = f \frac{L}{D} \frac{v^2}{2g} = \frac{8 f L Q^2}{\pi^2 g D^5}$$
  • $f$: ค่า Darcy Friction factor จากชาร์ต
  • $v = \frac{4Q}{\pi D^2}$ $[\text{m/s}]$
  • $D$ และ $L$ ต้องมีหน่วยเป็นเมตร $[\text{m}]$

3. Continuity Equation

สมการความต่อเนื่อง (มวลคงที่)

$$Q_1 = Q_2 = Q_3 \implies v_1 A_1 = v_2 A_2$$
  • สำหรับท่ออนุกรม: แปลง $v_2, v_3$ ให้อยู่ในรูป $v_1$
  • $v_2 = v_1 (D_1/D_2)^2$
  • สำหรับท่อขนาน: $Q_{\text{total}} = Q_2 + Q_3$

📋 จำแนกประเภทโจทย์ 3 รูปแบบในข้อสอบ (Exam Type Matrix)

ประเภทโจทย์ ข้อมูลที่โจทย์ให้ สิ่งที่โจทย์ถาม กลยุทธ์การคำนวณ (Solution Strategy)
Type 1: Direct Head Loss $Q, D, L, \varepsilon$ $h_f$ หรือ $\Delta P$ หา $v \to Re \to$ เปิดชาร์ตหา $f \to$ แทนสูตร $h_f = f \frac{L}{D}\frac{v^2}{2g}$ ทันที (ไม่ต้องสมมุติค่า)
Type 2: Flow / Velocity $\Delta P$ หรือ $h_f, D, L, \varepsilon$ $v$ หรือ $Q$ Trial & Error: จัดรูป $v = \sqrt{\frac{2g h_f}{\sum K + f L/D}} \to$ สมมุติ $f$ รอบที่ 1 จากโซน Fully Turbulent $\to$ หา $v \to Re \to$ อ่าน $f$ ใหม่จนนิ่ง
Type 3: Pipe Sizing $Q, h_f, L, \varepsilon$ เส้นผ่านศูนย์กลาง $D$ Trial & Error: จัดรูป $D = \left[\frac{8 f L Q^2}{\pi^2 g h_f}\right]^{0.2} \to$ สมมุติ $f_1 = 0.020 \to$ คำนวณ $D \to$ หา $v, Re, k/D \to$ เปิดชาร์ตได้ $f$ ใหม่ $\to$ 2 รอบตรง!

1. แกนแนวนอนด้านล่าง (Horizontal Axis):

คือค่า Reynolds Number: $Re = \frac{u d}{\nu} = \frac{v D}{\nu}$ วิ่งตั้งแต่ $10^3, 10^4, 10^5, 10^6, 10^7, 10^8$ แบบ Logarithmic

2. เส้นโค้งตระกูลขวา (Relative Roughness $k/d$):

มีค่าตั้งแต่ $0.00005$ ไปจนถึง $0.050$
จุดระวัง: ค่า $k$ (หรือ $\varepsilon$) ที่โจทย์ให้มาเป็นมิลลิเมตร ต้องหารด้วยเส้นผ่านศูนย์กลาง $D$ ที่เป็นมิลลิเมตรด้วย เช่น $k = 0.48\text{ mm}, D = 600\text{ mm} \implies k/D = 0.0008$

3. แกนแนวตั้งด้านซ้าย (Friction Factor $f$):

อ่านค่า $f$ ตรง ๆ วิ่งตั้งแต่ $0.010$ ถึง $0.100$
สังเกตในชาร์ตที่มีรอยปากกาสีน้ำเงินเขียนกำกับ:
• 0.023: ตรงกับโจทย์ข้อ 2 ($k/D = 0.0015, Re \approx 3 \times 10^5$)
• 0.019: ตรงกับโจทย์ข้อ 4 ท่อ 3 ($k/D = 0.0008, Re \approx 3.4 \times 10^5$)

⚠️ เทคนิคเดาค่า $f$ รอบแรก (Initial Guess Trick):

เมื่อเริ่มต้นรอบแรกที่เรายังไม่รู้ความเร็ว $v$ ให้มองหาเส้น $k/d$ ของท่อนั้น แล้วกวาดสายตาไปทางขวาสุดตรงบริเวณที่เส้นเริ่มขนานนอนราบ (Fully Turbulent Zone) แล้วอ่านค่า $f$ ทางซ้ายมาใช้เป็นค่าเดาแรก จะทำให้คำนวณรอบที่ 2 ได้ตรงเลย!

โจทย์ข้อที่ 1 (หน้า 2 และ 3)

ท่อ 3 ท่อนต่ออนุกรม วางเอียง $\theta = 5^\circ$ พร้อมการสูญเสียรอง

ผลต่างความดัน $\Delta P = 245.25\text{ kPa}$
$v_1 = 0.71\text{ m/s}, v_2 = 0.46\text{ m/s}, v_3 = 1.27\text{ m/s}$

ขั้นตอนที่ 1: กำหนด Datum และหาระดับความสูงปลายทาง $z_B$

กำหนดจุด A เป็น Datum ($z_A = 0$)

$$L_{\text{total}} = 80 + 120 + 80 = 280\text{ m}$$ $$z_B = 280 \sin 5^\circ = 24.40\text{ m}$$

ขั้นตอนที่ 2: ค่าสัมประสิทธิ์การสูญเสียรอง (Minor Losses)

  • ท่อ 1 ไป 2 (Sudden Expansion): $\frac{A_1}{A_2} = (0.4/0.5)^2 = 0.64 \implies K_{12} = 0.15 \implies h_{m,12} = 0.15 \frac{v_1^2}{2g}$
  • ท่อ 2 ไป 3 (Sudden Contraction): $\frac{A_3}{A_2} = (0.3/0.5)^2 = 0.36 \implies K_{23} = 0.35 \implies h_{m,23} = 0.35 \frac{v_3^2}{2g}$

ขั้นตอนที่ 3: ใช้สมการความต่อเนื่องดึงตัวแปรความเร็วให้เหลือ $v_1$ ตัวเดียว

$$v_2 = v_1 \left(\frac{0.4}{0.5}\right)^2 = 0.64 v_1$$ $$v_3 = v_1 \left(\frac{0.4}{0.3}\right)^2 = 1.78 v_1$$

ขั้นตอนที่ 4: ตั้งสมการพลังงานและรวมสัมประสิทธิ์

$$\frac{P_A - P_B}{\gamma} - z_B = \left[ 1.78^2 - 1 + f_1 \frac{80}{0.4} + f_2 \frac{120}{0.5}(0.64)^2 + f_3 \frac{80}{0.3}(1.78)^2 + 0.15 + 0.35(1.78)^2 \right] \frac{v_1^2}{2g}$$ $$\frac{245.25 \times 10^3}{9,810} - 24.40 = 25.00 - 24.40 = 0.60\text{ m}$$ $$0.60 = \left[ 3.427 + 200 f_1 + 98.3 f_2 + 845 f_3 \right] \frac{v_1^2}{2g}$$

โจทย์ข้อที่ 2 (หน้า 2 ข้อ 2)

หาขนาดท่อเส้นผ่านศูนย์กลางคงที่ ($D$) ไหลออกสู่อากาศ

$Q = 0.14\text{ m}^3\text{/s}, L = 1,500\text{ m}$
$D = 0.60\text{ m} \quad (598\text{ mm})$

1. ตั้งสมการพลังงานเพื่อหา Head Loss

ท่อมีขนาดคงที่ $v_1 = v_2$ ดังนั้น Velocity head ตัดกันได้ และปลายท่อเปิดสู่อากาศ $P_2 = 0$

$$\frac{P_1}{\gamma} + z_1 = \frac{P_2}{\gamma} + z_2 + h_f \implies h_f = \frac{P_1}{\gamma} - (z_2 - z_1)$$ $$h_f = \frac{105.13 \times 10^3}{9,810} - 10 = 10.717 - 10 = 0.717\text{ m}$$

2. แปลงสูตร Darcy-Weisbach ให้อยู่ในรูป $D$

$$h_f = \frac{8 f L Q^2}{\pi^2 g D^5} \implies D = \left( \frac{8 f L Q^2}{\pi^2 g h_f} \right)^{1/5}$$

3. สรุปการวนลูป Trial & Error

  • รอบที่ 1: สมมุติ $f_1 = 0.020 \implies D = 0.584\text{ m} \implies v = 0.523\text{ m/s} \implies Re = 3.05 \times 10^5, \frac{\varepsilon}{D} = \frac{0.9}{584} = 0.00154 \implies$ เปิดชาร์ตได้ $f_2 = 0.0226$ (จุดเดียวกับที่อาจารย์ขีดไฮไลท์ $0.023$ บนชาร์ต!)
  • รอบที่ 2: ใช้ $f_2 = 0.0226 \implies D = 0.598\text{ m} \approx 0.60\text{ m} \implies v = 0.498\text{ m/s} \implies Re = 2.98 \times 10^5, \frac{\varepsilon}{D} = 0.00150 \implies f = 0.0225$ (คงที่!)
ขนาดท่อที่ต้องการ: $D = 0.60\text{ m} = 600\text{ mm}$
โจทย์ข้อที่ 3 (หน้า 1 แผ่น 2)

ถังเก็บน้ำขนาดใหญ่ 2 ถัง เชื่อมด้วยท่อเอียง $12^\circ$ (หาขนาดท่อ $D$)

$Q = 12\text{ m}^3\text{/s}, L = 120\text{ m}$
$D = 1.44\text{ m} \quad (1,440\text{ mm})$

1. วิเคราะห์หาระดับผิวน้ำ $h_f = z_1 - z_2$

กำหนดปากท่อฝั่งซ้ายเป็น Datum ($z_{\text{in}} = 0$)

$$z_1 = 45.0\text{ m}$$ $$z_{\text{out}} = 120 \sin 12^\circ = 24.95\text{ m}$$ $$z_2 = z_{\text{out}} + 16.5 = 24.95 + 16.5 = 41.45\text{ m}$$ $$h_f = z_1 - z_2 = 45.0 - 41.45 = 3.55\text{ m}$$

2. การคำนวณหาเส้นผ่านศูนย์กลาง $D$

$$D = \left( \frac{8 f (120) (12)^2}{\pi^2 (9.81) (3.55)} \right)^{1/5}$$
  • รอบที่ 1: สมมุติ $f = 0.020 \implies D = 1.517\text{ m} \implies v = 6.64\text{ m/s} \implies Re = 1.01 \times 10^7, k/D = 0.00032 \implies f = 0.0153$
  • รอบที่ 2: ใช้ $f = 0.0153 \implies D = 1.439\text{ m} \implies v = 7.38\text{ m/s} \implies Re = 1.06 \times 10^7, k/D = 0.00033 \implies f = 0.0153$ (ตรงเป๊ะ!)
ขนาดท่อที่ต้องการ: $D = 1.44\text{ m} = 1,440\text{ mm}$
โจทย์ข้อสอบใหญ่ 15 คะแนน (หน้า 4)

โครงข่ายท่ออนุกรมผสมขนาน 4 ท่อน (หา $h_{AA \to BB}$)

กำหนด $h_3 = 0.42\text{ m}$
$h_{AA \to BB} = 1.24\text{ m}$

ขั้นที่ 1: วิเคราะห์ท่อ 4 เพื่อหา $h_4$

$$\frac{P_A - P_B}{\gamma} = (z_B - z_A) + h_{AB}$$ $$\frac{(910 - 811.41) \times 10^3}{9,810} = 10 + h_{AB} \implies 10.05 = 10 + h_{AB} \implies h_{AB} = 0.05\text{ m}$$ $$h_4 = h_{AB} \times \left(\frac{L_4}{L_{AB}}\right) = 0.05 \times \left(\frac{1000}{300}\right) = 0.17\text{ m}$$

ขั้นที่ 2: วิเคราะห์ท่อขนาน ($h_2 = h_3 = 0.42\text{ m}$)

  • ท่อ 3: $k/D_3 = \frac{0.48}{600} = 0.0008, f_3 \approx 0.019 \implies v_3 = 0.56\text{ m/s} \implies Q_3 = 0.16\text{ m}^3\text{/s}$
  • ท่อ 2: $k/D_2 = \frac{0.32}{800} = 0.0004, f_2 \approx 0.017 \implies v_2 = 0.70\text{ m/s} \implies Q_2 = 0.35\text{ m}^3\text{/s}$
  • อัตราการไหลรวม: $Q_{\text{total}} = Q_1 = Q_2 + Q_3 = 0.35 + 0.16 = 0.51\text{ m}^3\text{/s}$

ขั้นที่ 3: คำนวณ Head Loss ท่อ 1 ($h_1$)

$$v_1 = \frac{4(0.51)}{\pi (0.9)^2} = 0.80\text{ m/s}, \quad Re_1 = 7.2 \times 10^5, \quad \frac{\varepsilon_1}{D_1} = 0.0010 \implies f_1 = 0.0201$$ $$h_1 = (0.0201) \left(\frac{900}{0.9}\right) \frac{(0.80)^2}{2(9.81)} = 0.66\text{ m}$$

ขั้นที่ 4: รวม Head Loss ทั้งระบบ ($h_{AA \to BB}$)

$$h_{AA \to BB} = h_1 + h_2 + h_4 = 0.66 + 0.42 + 0.17 = 1.24\text{ m}$$
