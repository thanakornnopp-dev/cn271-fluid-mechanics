# วย 271 บทที่ 5 การไหลในท่อ: สรุปสูตรและเฉลย

เว็บสรุปสูตร ขั้นตอนทำโจทย์ และเฉลยทีละบรรทัด สำหรับเตรียมสอบย่อยเรื่อง Flow in Pipe วิชากลศาสตร์ของไหลสำหรับวิศวกรโยธา (อาจารย์สุนิสา สมิทธการ) มหาวิทยาลัยธรรมศาสตร์

**เปิดอ่าน:** https://thanakornnopp-dev.github.io/cn271-fluid-mechanics/

## มีอะไรในเว็บ (แต่ละหน้าคือ 1 แท็บบนแถบด้านบน)

| หน้า | เนื้อหา |
|---|---|
| สรุปสูตร | สูตรทั้งบท, ขั้นตอนทำโจทย์แต่ละประเภท (Type 1/2/3, อนุกรม, ขนาน, ปั๊ม), ตารางค่า K / f / ε, วิธีเขียนในห้องสอบ, จุดดัก |
| ข้อ 1–8 | ข้อสอบหลัก เฉลย 2 ชั้น: **เฉลยวิธีทำ** (เขียนส่งตามลำดับ) แล้ว **เฉลยละเอียด** (แนวคิด ขั้นที่ 1–3 สมการเลขกำกับ ตรวจสอบ) |
| สอบ A, B | โจทย์ 15 คะแนน: ท่ออนุกรมเอียง 5° และโครงข่ายท่อ 4 เส้น |
| ข้อ 9–13 | เสริม (นอกขอบเขตที่เพื่อนบอกว่าจะออก) ข้อ 11 ข้อมูลไม่ครบ |
| คิดเลข | เครื่องคิดเลขเดา f วนจนลู่เข้า ใช้ตรวจคำตอบที่ทำมือ |
| อ้างอิง | คำตอบทุกข้อ, วิธีอ่านชาร์ต, ศัพท์ไทย–อังกฤษ |

ปุ่มมุมขวาบน: **ฝึก** ซ่อนวิธีทำให้แตะดูทีละขั้น (ลองเขียนเองก่อน), **โหมดมืด/สว่าง** (จำค่าที่เลือก ครั้งแรกตามเครื่อง) เปิดครั้งเดียวตอนมีเน็ตแล้วอ่านออฟไลน์ได้

## ตรวจตัวเลข

ทุกคำตอบคำนวณซ้ำด้วย Colebrook-White ใน `scripts/pipeflow.py` และมี unit test ว่าตัวเลขใน `index.html` ตรงกัน:

```bash
python3 -m unittest discover -s scripts
```

ค่า f ที่อ่านจากชาร์ตในห้องสอบอาจต่างจาก Colebrook เล็กน้อย (ไม่เกิน ~2%) คะแนนให้ตามวิธีทำ

## แก้เนื้อหา

`index.html` สร้างจากไฟล์ Python ใน `scripts/site/` (ผู้ชมไม่ต้องใช้ Python)

```bash
python3 scripts/site/build.py          # สร้าง index.html ใหม่
python3 -m unittest discover -s scripts # ตรวจตัวเลข
python3 -m http.server                  # เปิดดู http://localhost:8000
```

```
index.html              ผลลัพธ์ (สร้างอัตโนมัติ อย่าแก้ตรง ๆ)
assets/style.css        หน้าตา (สว่าง/มืด) · app.js สลับหน้า ธีม โหมดฝึก · calc.js เครื่องคิดเลข
sw.js                   เก็บไฟล์ไว้อ่านออฟไลน์
scripts/pipeflow.py     ตัวคำนวณตรวจเลข + test_pipeflow.py
scripts/site/cheat.py   หน้าสรุปสูตร
scripts/site/core.py    ข้อ 1–8, สอบ A, B (ข้อ 7 อยู่ใน q7_section.html)
scripts/site/extra.py   ข้อ 9–13
scripts/site/tools.py   คิดเลข, อ้างอิง
scripts/site/common.py  ตัวช่วย (แถววิธีทำ, ตัดบรรทัดสมการยาว)
PRODUCT.md, DESIGN.md   เป้าหมายและระบบออกแบบ
```

ข้อควรระวังตอนเขียนสูตร: อย่าใส่ `·` ใน `\text{}` (KaTeX ขึ้นตัวแดง) ใช้ `\!\cdot\!` และใช้ `&lt;` แทน `<` ที่ตามด้วยตัวอักษรในข้อความ HTML
