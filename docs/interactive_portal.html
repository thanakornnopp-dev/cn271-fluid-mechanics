1 Energy Balance

สมการพลังงานรวม (General Energy)

สมดุลเฮดระหว่างจุดต้นทาง (1) และปลายทาง (2)

$$\frac{P_1}{\gamma} + \frac{v_1^2}{2g} + z_1 = \frac{P_2}{\gamma} + \frac{v_2^2}{2g} + z_2 + \sum h_L$$
  • • $\gamma = 9,810\text{ N/m}^3$ (น้ำมาตรฐาน)
  • • $z$: วัดเทียบกับแนว Datum เดียวกัน
  • • $\sum h_L = \sum h_f \text{ (หลัก)} + \sum h_m \text{ (รอง)}$
2 Major Loss

สมการ Darcy-Weisbach

การสูญเสียหลักเนื่องจากแรงเสียดทานในท่อ

$$h_f = f \frac{L}{D} \frac{v^2}{2g} = \frac{8 f L Q^2}{\pi^2 g D^5}$$
  • • $f$: สัมประสิทธิ์ความเสียดทาน (เปิดชาร์ตท่อ)
  • • ความเร็ว $v = \frac{Q}{A} = \frac{4Q}{\pi D^2}$ $[\text{m/s}]$
  • • $D$ ต้องมีหน่วยเป็นเมตร $[\text{m}]$ เสมอ
3 Continuity

สมการความต่อเนื่อง (มวลคงที่)

ใช้ยุบตัวแปรความเร็วให้เหลือตัวเดียว

$$v_2 = v_1 \left( \frac{D_1}{D_2} \right)^2, \quad v_3 = v_1 \left( \frac{D_1}{D_3} \right)^2$$
  • • ท่ออนุกรม: $Q_1 = Q_2 = Q_3 = Q$
  • • ท่อขนาน: $h_2 = h_3$ และ $Q_{\text{total}} = Q_2 + Q_3$
  • • ทำให้อาจารย์เห็นชัดเจนว่ายุบตัวแปรมาอย่างไร

🎯 ลำดับการทำ 4 ขั้นตอนตามที่อาจารย์ให้คะแนนเต็ม (Step-by-Step Template)

ขั้นตอนที่ 1

กำหนด Datum

ระบุระดับอ้างอิง $z=0$ ชัดเจน หากเป็นท่อเอียง ให้คำนวณ $z = L_{\text{tot}} \sin \theta$ เพื่อหาผลต่างความสูง

ขั้นตอนที่ 2

ยุบตัวแปรความเร็ว

เขียนสมการความต่อเนื่อง $Q = vA$ เพื่อแทน $v_2, v_3$ ให้อยู่ในรูป $v_1$ ตัวเดียว ป้องกันการติดหลายตัวแปร

ขั้นตอนที่ 3

ดึงตัวร่วมก้อนใหญ่

แทนพจน์การสูญเสียหลักและรอง แล้วดึง $\frac{v_1^2}{2g}$ ออกมา รวมค่าคงที่ไว้ในวงเล็บเดี่ยว

ขั้นตอนที่ 4

วนลูป Trial & Error

สมมุติค่า $f$ รอบแรกจากโซน Fully Turbulent หรือ $f=0.020$ คำนวณหา $v \to Re \to$ เปิดชาร์ตได้ $f$ ใหม่ตรงเดิม!

⚠️ 5 จุดดักคะแนนในห้องสอบที่นักศึกษามักพลาด (Common Exam Traps)

1. ลืมแปลงมิลลิเมตรเป็นเมตร: ค่าความขรุขระ $\varepsilon$ ให้มาเป็น mm ต้องแปลงให้เป็นหน่วยเดียวกับเส้นผ่านศูนย์กลาง $D$ เช่น $\frac{0.08\text{ mm}}{400\text{ mm}} = 0.0002$
2. หน่วยความดัน kPa: ต้องคูณ $10^3$ ก่อนหารด้วย $\gamma = 9,810\text{ N/m}^3$ เพื่อแปลงเป็นเฮดเมตร
3. เครื่องหมายความสูงเนิน: น้ำไหลขึ้นเนิน $z_2 > z_1$ เมื่อย้ายมาลบกับฝั่งซ้ายของสมการ ต้องติดลบ ($\Delta P/\gamma - z_2$)
4. ท่อขนานห้ามบวกเฮดรวม: การสูญเสียพลังงานช่วงท่อขนานคิดเพียงเส้นเดียว ($h_2 = h_3 = 0.42\text{ m}$) ห้ามเอามาบวกกัน

3 สเต็ปการเปิดชาร์ตในห้องสอบ

  1. หา Relative Roughness ($k/D$):
    นำความขรุขระ $\varepsilon$ (mm) หารด้วยเส้นผ่านศูนย์กลางท่อ $D$ (mm) แล้วมองหาเส้นโค้งฝั่งขวา
  2. ลากตามแนวเส้น $k/D$ มาตัด $Re$:
    ดูค่า $Re$ แกนแนวนอนด้านล่าง ลากเส้นตรงขึ้นไปตัดกับเส้นโค้ง $k/D$
  3. กวาดสายตาไปทางซ้ายสุด:
    อ่านค่า Friction Factor ($f$) ตรงแกนตั้งด้านซ้าย
💡 ทริคเดาค่ารอบแรก (Trial 1):

เมื่อยังไม่รู้ความเร็ว $v$ ให้มองหาเส้น $k/D$ แล้วกวาดสายตาไปขวาสุดตรงช่วงที่เส้นเริ่ม **นอนราบ (Fully Turbulent Zone)** อ่านค่า $f$ ฝั่งซ้ายมาใช้ทันที จะทำให้คำนวณรอบที่ 2 ได้คำตอบตรงเลย

ข้อสอบข้อที่ 1 ท่ออนุกรม 3 ท่อน วางเอียง $\theta = 5^\circ$

การไหลในท่ออนุกรมวางเอียง พร้อม Sudden Expansion & Contraction

คำตอบสุดท้าย:
$v_1 = 0.71\text{ m/s}, \; v_2 = 0.46\text{ m/s}, \; v_3 = 1.27\text{ m/s}$
Schematic Illustration (ภาพจำลองระบบท่อจริงตามโจทย์):

1. คำนวณความสูงปลายทาง $z_B$ เทียบ Datum:

ความยาวตลอดแนวเอียงรวม: $L_{\text{tot}} = 80 + 120 + 80 = 280\text{ m}$
ดังนั้นระดับความสูงที่จุด B คือ:

$$z_B = 280 \sin(5^\circ) = 24.40\text{ m}$$

2. หาค่าสัมประสิทธิ์การสูญเสียรอง (Minor Losses):

รอยต่อ 1 ไป 2 (Sudden Expansion):

$$\frac{A_1}{A_2} = \left(\frac{0.4}{0.5}\right)^2 = 0.64 \implies K_{12} = 0.15$$

คูณกับความเร็วก่อนขยาย: $h_{m1} = 0.15 \frac{v_1^2}{2g}$

รอยต่อ 2 ไป 3 (Sudden Contraction):

$$\frac{A_3}{A_2} = \left(\frac{0.3}{0.5}\right)^2 = 0.36 \implies K_{23} = 0.35$$

คูณกับความเร็วหลังหด: $h_{m2} = 0.35 \frac{v_3^2}{2g}$

3. ใช้สมการความต่อเนื่องดึง $v_2, v_3$ ในรูป $v_1$:

$$v_2 = v_1 \left(\frac{0.4}{0.5}\right)^2 = 0.64 v_1, \qquad v_3 = v_1 \left(\frac{0.4}{0.3}\right)^2 = 1.78 v_1$$

4. ตั้งสมการพลังงานรวมและดึงตัวร่วม $\frac{v_1^2}{2g}$:

$$\frac{P_A - P_B}{\gamma} - z_B = \left[ (1.78^2 - 1) + 200 f_1 + 240(0.64)^2 f_2 + 266.7(1.78)^2 f_3 + 0.15 + 0.35(1.78)^2 \right] \frac{v_1^2}{2g}$$ $$\frac{245.25 \times 10^3}{9,810} - 24.40 = 25.00 - 24.40 = 0.60\text{ m}$$ $$0.60 = \left[ 3.427 + 200 f_1 + 98.30 f_2 + 844.91 f_3 \right] \frac{v_1^2}{2g}$$
รอบที่ ค่า $f$ สมมุติ ($f_1, f_2, f_3$) ผลรวมในวงเล็บ $v_1$ คำนวณ (m/s) ค่า $Re$ ค่า $f$ ใหม่จากชาร์ต
1 0.014, 0.015, 0.016 21.22 0.745 m/s 3.0×10⁵, 2.4×10⁵, 4.0×10⁵ 0.0163, 0.0175, 0.0173
2 0.0163, 0.0175, 0.0173 23.02 0.713 m/s 2.9×10⁵, 2.3×10⁵, 3.8×10⁵ 0.0163, 0.0175, 0.0173 (ตรงเดิม!)
✅ ผลลัพธ์สมบูรณ์: $v_1 = 0.71\text{ m/s}, \quad v_2 = 0.46\text{ m/s}, \quad v_3 = 1.27\text{ m/s}$
ข้อสอบข้อที่ 2 หาขนาดเส้นผ่านศูนย์กลางท่อ $D$ ที่ปล่อยออกสู่บรรยากาศ

การออกแบบขนาดท่อ (Pipe Sizing with Elevation & Open Outlet)

ขนาดท่อที่ต้องการ:
$D = 0.60\text{ m} \quad (598\text{ mm})$

1. ข้อมูลที่โจทย์ระบุ:

  • อัตราการไหล $Q = 0.14\text{ m}^3\text{/s}$
  • ความยาวท่อ $L = 1,500\text{ m}$
  • ความขรุขระ $\varepsilon = 0.9\text{ mm}$
  • ความสูงปลายทาง $z_2 - z_1 = 10\text{ m}$
  • ความดันต้นทาง $P_1 = 105.13\text{ kPa}$, ปลายทางออกสู่อากาศ $P_2 = 0$

2. หา Head Loss ($h_f$):

ท่อขนาดสม่ำเสมอทำให้ $v_1 = v_2$ Velocity head จึงตัดกันหมด:

$$h_f = \frac{P_1}{\gamma} - (z_2 - z_1) = \frac{105.13 \times 10^3}{9,810} - 10 = 0.717\text{ m}$$

3. สรุปการวนลูป 2 รอบ (Trial & Error):

จาก Darcy-Weisbach จัดรูปหา $D$:

$$D = \left( \frac{8 f L Q^2}{\pi^2 g h_f} \right)^{1/5} = 1.2766 \times f^{0.2}$$
รอบที่ 1: สมมุติ $f_1 = 0.020$
$\implies D_1 = 0.584\text{ m} \implies v = 0.523\text{ m/s} \implies Re = 3.05 \times 10^5$
$\frac{\varepsilon}{D} = \frac{0.9}{584} = 0.00154 \implies$ เปิดชาร์ตได้ f = 0.023 (จุดขีดปากกาบนชาร์ตหน้า 1!)
รอบที่ 2: แทนค่า $f_2 = 0.0226$
$\implies D_2 = 0.598\text{ m} \approx 0.60\text{ m} \implies Re = 2.98 \times 10^5$
$\frac{\varepsilon}{D} = \frac{0.9}{598} = 0.00150 \implies f = 0.0225$ (ตรงเดิม ลู่เข้าแล้ว!)
ขนาดท่อที่ต้องเลือกใช้: $D = 0.60\text{ m} = 600\text{ mm}$
ข้อสอบข้อที่ 3 ถังเก็บน้ำขนาดใหญ่มาก 2 ถัง เชื่อมด้วยท่อเอียง $12^\circ$

การหาขนาดท่อระหว่างถังเก็บน้ำ (Two Huge Reservoirs)

ขนาดท่อที่ต้องการ:
$D = 1.44\text{ m} \quad (1,440\text{ mm})$

1. วิเคราะห์หาระดับผิวน้ำ $h_f$:

กำหนดทางเข้าท่อฝั่งซ้ายเป็น Datum ($z_{\text{in}} = 0$):

• ระดับผิวน้ำถัง 1: $z_1 = 45.0\text{ m}$
• ทางออกท่อฝั่งขวา: $z_{\text{out}} = 120 \sin(12^\circ) = 24.95\text{ m}$
• ระดับผิวน้ำถัง 2: $z_2 = 24.95 + 16.5 = 41.45\text{ m}$
• ผลต่างเฮดขับดัน: $h_f = 45.0 - 41.45 = 3.55\text{ m}$

2. การคำนวณหาขนาดท่อ $D$:

$$D = \left( \frac{8 f (120)(12)^2}{\pi^2(9.81)(3.55)} \right)^{1/5}$$
  • • รอบที่ 1: สมมุติ $f = 0.020 \implies D = 1.517\text{ m} \implies v = 6.64\text{ m/s} \implies Re = 1.01 \times 10^7, k/D = 0.00032 \implies f = 0.0153$
  • • รอบที่ 2: ใช้ $f = 0.0153 \implies D = 1.439\text{ m} \implies Re = 1.06 \times 10^7 \implies f = 0.0153$ (ตรงเป๊ะ)
ขนาดเส้นผ่านศูนย์กลางท่อ: $D = 1.44\text{ m}$
ข้อสอบใหญ่ 15 คะแนน ท่ออนุกรมผสมขนาน 4 ท่อน (หา Major loss จาก AA ถึง BB)

การวิเคราะห์โครงข่ายท่อขนาน (Parallel & Series Pipe Network)

Head Loss รวมทั้งระบบ:
$h_{AA \to BB} = 1.24\text{ m}$
ขั้นที่ 1: วิเคราะห์ท่อ 4

จุด A และ B บนท่อ 4:

$$\frac{P_A - P_B}{\gamma} = 10 + h_{AB}$$ $$10.05 = 10 + h_{AB}$$ $$h_{AB} = 0.05\text{ m}$$ $$h_4 = 0.05 \times \frac{1000}{300} = 0.17\text{ m}$$
ขั้นที่ 2: วิเคราะห์ท่อขนาน

ท่อ 2 และ 3 ขนานกัน:

$$h_2 = h_3 = 0.42\text{ m}$$

• ท่อ 3: $Q_3 = 0.16\text{ m}^3\text{/s}$
• ท่อ 2: $Q_2 = 0.35\text{ m}^3\text{/s}$
• รวม: $Q_{\text{tot}} = 0.51\text{ m}^3\text{/s}$

ขั้นที่ 3: หา $h_1$ ในท่อ 1

ท่อ 1 รับ $Q_{\text{tot}} = 0.51$:

$$v_1 = \frac{4(0.51)}{\pi(0.9)^2} = 0.80\text{ m/s}$$ $$Re_1 = 7.2 \times 10^5 \implies f_1 \approx 0.0201$$ $$h_1 = 0.66\text{ m}$$
ขั้นที่ 4: รวม Head Loss

กฎของท่อผสม:

$$h_{AA \to BB} = h_1 + h_2 + h_4$$ $$h_{AA \to BB} = 0.66 + 0.42 + 0.17$$ $$= 1.24\text{ m}$$

*ท่อขนานคิดเพียงเส้นเดียว (0.42 m) ห้ามบวกซ้ำ
